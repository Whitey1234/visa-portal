# Visa Service Portal

This is a simple visa service portal built with Next.js and Tailwind CSS.

## Features

- **Theme Toggle:** Users can toggle between light and dark themes.
- **Page Transitions:** Animated transitions between pages.
- **Scroll-triggered Animations:** Elements fade in as you scroll down the page.
- **Lottie Animations:** The site uses Lottie for animations.
- **Responsive Design:** The site is fully responsive and works on all devices.
